# 🍽️ Swiggy Restaurants Data Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Swiggy Restaurants Data Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes restaurant data to understand restaurant distribution, food types, pricing, ratings, delivery time, and city/area-wise trends.

The main objective of this project is to transform raw restaurant data into meaningful and interactive business insights using data visualization and business intelligence techniques.

---

## 🎯 Project Objectives

- Analyze the overall Swiggy restaurant dataset.
- Identify the most commonly served food types.
- Find areas with the highest number of restaurants.
- Analyze average prices across different areas.
- Identify cities with the highest restaurant concentration.
- Analyze average restaurant ratings.
- Analyze average delivery time.
- Provide interactive filtering using City and Area.
- Create an easy-to-understand Power BI dashboard.

---

## 🛠️ Tools & Technologies

## 📈 Dashboard Features

### 1. Top 5 Most Served Food Types

A donut chart represents the distribution of the top five food types:

- Indian
- Chinese
- North Indian
- Fast Food
- South Indian

### 2. Top 10 Areas with Most Restaurants

A column chart shows the areas having the highest number of restaurants.

### 3. Average Price-Wise Most Expensive Areas

A bar chart compares the average restaurant prices across different areas.

### 4. Top 10 Cities with Most Restaurants

A map visual represents the geographic distribution of restaurants across major Indian cities.

### 5. City Filter

Users can select a particular city to analyze the corresponding restaurant data.

### 6. Area Filter

Users can select an area to explore restaurant-level trends for that location.

## 🔍 Key Insights

- The dataset contains **8,680 restaurants**.
- The overall average restaurant rating is **3.66**.
- The average restaurant price is approximately **348.44**.
- The average delivery time is approximately **53.97 minutes**.
- Indian food is the largest category among the top five food types displayed.
- The dashboard highlights areas with a high concentration of restaurants.
- The map provides a geographical view of restaurant distribution across cities.
